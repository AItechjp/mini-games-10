# Public Commons

The user explicitly requires every Commons tool to work without login or account
registration. Do not add an account gate, owner-only viewer check, or email/password
flow. The canonical site remains https://aitechd.com/commons/.

Anonymous browser keys identify a guest's posts and recent rooms. Keep those keys
private, derive actors on the server, and preserve per-room participation and edit
rules. Existing saved rooms must remain intact; never list all users' rooms publicly.
The former Sites URL is a public redirect only.
