出典・収録問題

QUIZ RAIDは、法律500問・IT500問を収録したオリジナルの学習ゲームです。過去の試験問題を転載した問題集ではありません。

法律は制度210問、事例35問、条文の穴埋め255問。ITは用語200問、計算・コード・データ操作の演習300問です。演習は20形式×15問で、数値やデータが異なる練習問題を含みます。すべてに解説と原典または学習参考資料のリンクを付けています。

法律の資料

AItechのオリジナル学習カードと、2026年9月10日取得のe-Gov条文資料を使用しています。条文の穴埋めは、問題に示した法律・条文の語句を問います。改正法の適用や具体的な事案の判断は、問題文に記載した原則・条件を前提とします。

  • e-Gov 法令検索：憲法、民法、刑法、会社法、民事訴訟法、刑事訴訟法、行政事件訴訟法、行政手続法など。各問題に対応する法律へのリンクがあります。
  • 裁判所：判例・司法制度の参考資料。

ITの学習参考資料

説明と計算問題はAItechによるオリジナルです。特定の資格試験の公式問題や、合格を保証する教材ではありません。計算問題の答えは、解説内の式と問題に示した条件で確認できます。用語の詳しい定義・背景は次の一次資料を参照してください。

  • IPA 試験要綱・シラバス：情報基礎、アルゴリズム、ネットワーク、マネジメントの学習範囲。
  • IPA 安全なウェブサイトの作り方：SQLインジェクション、XSS、CSRFなど。
  • NIST セキュリティ用語集：暗号、認証、アクセス制御など。
  • MDN JavaScript ガイド：コード、配列、演算子、非同期処理。
  • PostgreSQL 公式チュートリアル：SQL、表、結合、トランザクション。
  • Google Machine Learning Crash Course：分類、回帰、評価、過学習。
  • Pro Git：バージョン管理。
  • IETF RFC 8200：IPv6。

プレイと保存

2人協力は同じ端末の画面を共有して遊びます。1人モードではCPUが2Pを担当します。オンライン通信で別端末を接続する機能はありません。復習は時間制限なしで、その時点の間違えた問題を一巡します。

挑戦した問題、間違えた問題、ベストスコアはこのブラウザのローカル保存領域に記録します。名前を含め、回答記録を外部サーバーには送信しません。
