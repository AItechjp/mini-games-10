# BAYLINE — LIVING CITY / BUILD 03

2026年9月12日。独自のブラウザ向け3Dオープンワールドの更新です。GTAの公式作品や商用GTA相当の完成度を示すものではありません。

## 追加・変更

- 街全体で288人の歩行者をシミュレーション。歩道・横断歩道の経路探索、信号待ち、立ち止まり、車の接近と銃声への逃走反応。
- 一般車は信号、前方車両、前方の歩行者に応じて減速・停止します。プレイヤーの運転は自動停止しません。
- 歩行者・プレイヤー・敵の人物モデルを作り直し、顔、服の織り目、靴、膝・肘の関節を追加。歩行・走行時の動きも更新。
- 店舗の棚・商品・照明・ガラス、8種類の看板、バス停、カフェのテーブルと椅子、プランター、道路設備を追加。店舗は外から見る表現で、入店機能ではありません。
- 建物の窓の奥行き表現、路面の法線マップ、風に揺れるヤシの葉を追加。
- 最高画質かつ雨天時のみ、水たまりの平面反射を有効化。レイトレーシングではありません。
- 協力プレイではホストが歩行者の動きを計算し、両プレイヤー近くの歩行者を同期。新規のアカウント登録・ログインは追加していません。
- ダッシュ14 m/s、縦横画面切り替え、既存セーブ形式、車両・ミッションは維持。

## 画質ごとの歩行者の描画上限

| 画質 | 同時描画の上限 | 表示範囲 |
| --- | ---: | ---: |
| 軽量 | 20人 | 65m |
| 標準 | 36人 | 100m |
| 高画質 | 64人 | 155m |
| 最高画質 | 96人 | 200m |

上限まで常に表示されるわけではなく、近くにいる人だけを表示します。街全体の288人と画面内の人数は別です。スマホの実機性能は端末ごとに異なり、特定のFPSは保証しません。

## 起動と検証

エンジンを含むソース一式をHTTPサーバーから配信し、`bayline/` を開きます。HTMLをファイルとして直接開く方式はES Modulesで動作しません。

```
python3 -m http.server 8000
node tests/bayline-living-core.mjs
```

実ブラウザの検証は `.github/workflows/bayline-living.yml` で実行します。画面を代用品に置き換えず、WebGL、最高画質の反射、2つのブラウザ間の実通信、タッチ画面の縦横切り替えを検証するテストです。検証結果はGitHub Actionsの `bayline-living-verification` に保存します。

この更新は製品版GTA並みのフォトリアルなモデル・アニメーション・物理・演出を達成したものではありません。60分通しプレイやAndroid/iPhone実機での全機能検証を完了したという意味でもありません。
