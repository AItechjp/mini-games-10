# AItech アプリ別の改善一覧

対象はゲーム16本とコモンズ17本の計33アプリ。各20項目、計660項目です。
共通する機能は共通の実装を使い、開始手順・操作・困りごと・メモの用途・関連リンクはアプリ別に用意します。既存機能の欠陥を660件発見したという意味ではなく、今回追加・改善する具体的な項目です。

定期実行は停止済みです。この一覧を対象とする一括の改善・公開として進めます。

状態：実装済み。検証範囲と公開結果は末尾の記録を参照してください。

## 対象データと検証の考え方

個人メモの書き出しは、対局・答案・写真・ルーム投稿などのバックアップではありません。今回のメモと設定だけを扱い、既存の保存データや匿名参加キーは読み出しません。共有するのはアプリの入口です。ルームの招待には各アプリ本来の招待機能を使います。

共通機能のデータ保護と操作を検証し、各アプリへの組み込み・導線・ゲームの停止処理を確認します。オンライン対戦の相手や制限時間は、案内を開いても止まりません。

## 今回まとめて保持する追加改善

公開元に入った更新も統合しています。ホワイトボードのPNG保存（背景・解像度・コピー）、カメラの3秒／10秒タイマー・取消・グリッド、表示内容の記録、検索結果の比較表、アプリ本体の文字・行間・操作ボタン設定を残しました。これらはアプリメニューの「画面設定・記録・比較を開く」から使えます。PNGと撮影の操作は各アプリ本体にあります。

## 検証記録

統合したソースで、Commonsの型検査と本番ビルド、33アプリの経路、公開配布物、メモの保存・復元・競合・破損・容量不足の検査が通過しました。AETHER DUELは20件のルール検査と32回のCPU対戦を通過しています。ブラウザでの操作検査と公開完了は、対応するリリース結果で確認します。
