# 予備試験サイト 継続改善記録

更新日: 2026-09-11

## 守る範囲

- 短答は実際の公表過去問だけを出題する。生成問題・推測した正答は追加しない。
- 論文は法律基本7科目と民事・刑事実務基礎だけを扱い、選択科目は追加しない。
- 問題・正答・出題趣旨・独自教材を画面上で区別する。
- 合否を保証・予測しない。到達判定は条件と計算根拠を画面に明示する。
- 法改正や正答の確認には、法務省、e-Gov、裁判所など一次資料を優先する。

## 2026-09-11 の改善

- 短答の各論点から対応する論文講義へ直接移動できるようにした。
- 短答の回答後に、根拠・各記述の訂正・次回の見分け方を残す肢別メモを追加した。
- 短答の到達判定を、範囲、直近正答率、別日定着、年度別時間演習、一般教養、期限復習に分解した。
- 論文135題すべてで、公式出題趣旨を1〜8項目に区切って答案と照合し、確認状態を保存できるようにした。
- 論文の到達判定を、講義の別日再現、9分野の構成・起案・書き直し・定着、4科目群の完答に分解した。
- 到達判定、出題趣旨チェック、保存データの往復を自動テストに追加した。

## 次の優先順位

1. 法務省の正答PDFを確保し、予備試験の未収録法律問題を正答・配点・解答欄単位で再照合する。正答を一次資料で確定できない設問は除外を維持する。
2. 令和8年短答の全問題冊子・正答・配点を法務省資料から取得し、既存ビルダーと監査テストで追加する。
3. 短答の全肢解説は、公式資料・現行条文・判例への出典を設問ごとに付けられるものから追加する。市販解説の転記や自動生成だけの解説は追加しない。
4. 論文の各出題趣旨チェックを設問番号・論点・評価事実にさらに分ける場合も、公式文言と独自整理を別表示にする。
5. e-Gov条文の施行日と過去問の基準日を科目別に監査し、改正影響のある問題に個別表示を加える。
6. 毎回、`node tests/yobi-past-source.mjs`、JavaScript構文確認、静的ビルドを通してから公開する。

## 公開手順

1. `origin/main` を取得し、同時更新を取り込む。
2. データ件数・出典・ID一意性・採点・保存復元・タイマー・選択科目除外を検証する。
3. `node scripts/build-static.mjs` で公開物を構築する。
4. `main` に通常更新し、force pushは使わない。
5. GitHub Pagesのワークフロー完了後、公開URLと主要アセットが同じ版でHTTP 200になることを確認する。
