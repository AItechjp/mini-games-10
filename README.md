# 60秒ミニゲームズ

ブラウザだけで遊べる60秒ミニゲーム10本をまとめた静的サイトです。

## ゲーム
1. ターゲットラッシュ
2. 60秒連打
3. ナンバーハント
4. カラー判断
5. メモリーフラッシュ
6. 計算ブリッツ
7. スターキャッチ
8. リアクション
9. タイピングスプリント
10. HIGH or LOW

## ローカル実行
`index.html` をブラウザで開くだけでも動きます。

## GitHub Pages
1. GitHubでPublicリポジトリを作成
2. このフォルダの `index.html`, `styles.css`, `app.js`, `README.md` をリポジトリ直下へ置く
3. GitHubの `Settings` → `Pages`
4. `Build and deployment` を `Deploy from a branch`
5. Branch を `main`、Folder を `/(root)` にして保存

数十秒〜数分後に `https://<username>.github.io/<repository>/` で公開されます。
